## D3 — what the implementation copies

- **Header:** serif "Tier List" `clamp(32px, 6vw, 72px)`, "Tham khảo tier list của **…** · Cập nhật dd/mm/yyyy".
- **Tabs** "Nhân vật / Đội hình / Thông tin": page-tab style (serif 20 px, 16 px ≤ 768, gold 2 px underline), real
  tablist (tabpanel, aria-controls, roving tabindex, ←/→). Đội hình / Thông tin exist only with content; one tab left →
  no tab bar (`display:none`).
- **Sticky tool bar, Nhân vật tab only:** search field (accent-insensitive VI + CN name, ≤ 320 px) + one 36 px filter
  icon (count badge in gold when active) + result line ("16/48 Khí Giả · Viễn Kích · “kim” · Xoá lọc"; on phones only
  while filtering). Search and filters never apply to teams.
- **Filter:** wide screens = non-modal popover under the icon (no scrim, closes on outside click / Esc); ≤ 640 px =
  modal bottom sheet with scrim, safe-area padding, 44 px chips, "Còn N Khí Giả". Chips: job (game job icon + name) and
  rarity (DESIGN `-vivid` catalogue-filter style), each with its result count; a chip that would give 0 is disabled;
  chips update in place (focus stays). Legend repeated in the popover. "Xoá lọc" + "Đóng".
- **Legend** drawn with the badge chips: "[Z3] mốc Trí Tri tối thiểu · [HC] cần Hoán Chương · không nhãn = không cần mốc
  · trong một tier, bên trái mạnh hơn · bấm để xem build".
- **Groups:** no boxes — 40 px space + one hairline; description serif 500 20 px (16 px phone) above the group; one row
  per tier: rank `<h2>` serif 700 72 px (44 px phone, inline with its count) + "N Khí Giả" 12 px; gold only on the
  list's first tier (never moves to another tier when filtered).
- **Tile** (`CharacterTile`): square 96 px portrait (4 per row on phones), 6 px, strong-hairline border → gold on
  hover (no zoom, no lift), the game's `ui_ty_kp_pz_<rare>` glow over the bottom 36 %, badges Z/HC bottom-right with a
  `title` ("Trí Tri 3 · cần Hoán Chương"), name 500 13 px (12 px, 3 lines on phones), `aria-label` = name + badges +
  job + rarity; link to the character's Build tab.
- **Teams:** `<h2>` serif 26 px name, note, member tiles; no filtering, no dimming.
- **Empty state:** "Không có Khí Giả nào khớp. Xoá lọc".
